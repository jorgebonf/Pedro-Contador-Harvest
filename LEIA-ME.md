# Pedro · O Contador da Harvest — v1.6.0

## Atualizar no GitHub (repositório pedro-harvest)
1. Extraia o ZIP.
2. No repositório: Add file → Upload files → arraste TODO o conteúdo da pasta (inclusive a pasta icons).
3. Commit changes. Aguarde alguns minutos.
4. Feche e abra o Pedro com internet para receber a versão nova. Os dados não são apagados.

## Novidades
- Glossário sincronizado com o HV26_Glossário de Despesas Padrão (códigos Harvest, códigos da descrição do Argo, tipos e textos).
- Perdiem: R$ 25,00 por noite. Quem já usava o Pedro recebe a atualização das categorias automaticamente ao abrir (despesas já lançadas não mudam de valor).
- Tela de lançamento de despesa sem os códigos (eles continuam no Glossário, na aba Argo, na lista de despesas e nas planilhas).
- Tick de "Prestada no Argo" e seleção de várias despesas; Planilha e backup (Excel + JSON); almoço sem trava de feriado; tela sem zoom.

## Dados
- Cada aparelho tem a sua base. Use Backup JSON para trocar de aparelho.
- Nunca suba backups ou planilhas de despesas para o GitHub (repositório público).
